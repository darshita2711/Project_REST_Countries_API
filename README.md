## Overview

### The Challenge

Users should be able to:
- See all countries from the API on the homepage
- Search for a country using an input field
- Filter countries by region
- Toggle the color scheme between light and dark mode

### What I learned

Building this project was a fantastic way to practice working with asynchronous JavaScript and external APIs. Structuring the application using modular files (`script.js`, `api.js`, `ui.js`, and `theme.js`) helped keep the codebase clean and maintainable. One key learning experience was handling nested JSON data paths and combining text search and region filters seamlessly.
